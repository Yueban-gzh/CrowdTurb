# D 分析与优化模块

已实现轨迹完整性校验、网格聚合、指标/热点、自动多参数候选、可比性检查及带修改预算的结果比较。当前只有 Mock 与手算验证，没有完整 STDDN 场馆运行或真实优化结论。

分工见 [ADR 0002](../../docs/decisions/0002-stddn-trajectory-and-passage.md)，接口见 [轨迹与分析契约](../../contracts/trajectory-analysis.md)。C 负责真实仿真，D 不实现 ONNX 积分、路径、碰撞和退出判定。

## 分析能力

- 固定人员的 ID、时间、掩码、初始状态哈希和退出事件一致性检查。
- 轨迹转密度/平均速度，独立输出聚合场与分析结果。
- 最后时刻残留人数、累计拥堵面积时间、出口累计人数。
- 逐格热点时段、ix/iy、单位、来源和状态。
- 阈值必须显式提供，只支持整格有效面积和固定人口场景。
- 密度支持原 cell 统计及实验性的 gaussian_visible。后者按物理带宽分配人员质量，仅使用掩码中可直线到达的网格中心，并逐人归一化保持人数；未完成真实数据校准，不替代安全标准，默认仍为 cell。

## 候选能力

手动列表或从 A 声明范围自动生成有限组合，保留上下界和当前值；根据候选预算减少内部采样点，最低组合数仍超预算时要求减少参数或增大预算。所有修改交给 A 校验并按输入去重。自动采样只是候选搜索，不代表仿真或最优性。

## 比较能力

对每个候选重新应用几何变化并重算哈希、掩码与修改量；核对实际轨迹的人数、初始支撑区域、版本和几何。比较初始人员摘要、行为摘要、模型、种子、仿真设置、网格和完整观测时间轴，不一致标不可比较。

每次比较统一重算指标，不能混用不同阈值或密度方法的预计算数值。先检查四类明确的修改预算，残留人数为主、拥堵量为辅；任一效果指标变差同时另一改善时标 tradeoff，不自动推荐。仅在“至少一项改善且另一不变差”的候选中按残留人数/拥堵量排序，无合格改善则保留基准。尺寸修改无约定成本，暂不参与排名。没有把米、平方米和人数混成总分。
