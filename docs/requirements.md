# 四周需求基线草案

状态：从 V5 材料整理，待首次组会评审。需求来源见 [资料索引](references/README.md)；下面的编号由仓库新增，不是原文编号。当前没有任何产品需求被标记为已完成。

## 产品与范围

五人四周完成单层体育馆原型。核心用户通过配置建筑和初始场，运行连续密度 / 速度场求解，查看 3D 主视图及 2D 俯视图，分析拥堵，评价至少一个建筑参数的候选变化。

- 必须：示例场馆、基本编辑、真实 PDE、3D 展示、基础指标、真实布局变量、同条件比较和统一入口。
- FNO：留下训练 / 推理实验及真实误差说明；产品快速预测和候选初筛是争取项，失败时继续用 PDE。
- 不纳入本轮：完整 CAD/BIM、多楼层、复杂群体行为、精细人物动画、多人在线编辑、复杂 LLM 系统、工程级疏散认证。

## 功能需求

### REQ-01 场景配置与保存

负责人 A，E 提供保存接口。载入单层示例体育馆，修改出口或局部通道和初始密度、边界配置，保存并重新打开。验收时比较修改前后场景文件，确认位置、参数及版本一致，且无须改代码或手工替换数据。非法几何、负密度和不支持的配置应给出可读提示，不能静默运行。

### REQ-02 PDE 求解

负责人 C，E 接入。独立执行 PDE 基准，并输出随时间变化的密度、速度场及运行元数据。使用 C 在第一周评审确定的方程、边界与离散方案；在实验记录中给出步长、单位、质量守恒 / 非负性等验证指标及容差。当前不规定方程或承诺精度、人数规模。

### REQ-03 3D 与俯视回放

负责人 B。读取 A 的建筑和 C 的连续场，显示 3D 场馆、2D 俯视、密度热力、流向与时间控制。示意粒子跟随连续速度场运动；验证时间、坐标和障碍处理。粒子数不得作为真实人数，粒子路径不得作为个体疏散结论。

### REQ-04 指标与诊断

负责人 D。展示拥堵热点、出口流量、残留人数等基础指标，注明定义、单位和阈值来源 / 假设。用小型可手算场验证计算。连续密度积分不能直接套用早期个体轨迹的旅行时间定义。

### REQ-05 候选布局与公平对比

负责人 D，A 提供可调参数和几何约束，E 调度求解。至少一个出口或通道建筑参数真正发生变化；候选先通过几何与可达性检查，然后执行真实 PDE。除设计变量外，保持相同初始场、边界策略、时间范围、网格、求解配置和种子策略；如需重采样须记录一致性方法。展示指标、修改量、代价及无改善结果。不得以 Mock 或只修改人数冒充建筑优化。

### REQ-06 系统任务与结果管理

负责人 E。统一网页入口连接配置、求解、回放、分析和优化；保存项目、场景版本和运行结果。计算过程有状态，失败有原因。以固定场馆从头到尾演示，无须途中改代码、手动换结果；按说明可重新启动并复现关键结果。

### REQ-07 FNO 实验与回退

负责人 C。保留训练与推理实验记录、数据生成方式、训练 / 验证 / 测试划分、模型版本、误差口径、速度对比条件与适用范围。避免测试集泄漏；同一硬件比较并区分训练、加载和推理耗时。未达标或实验失败如实记录并说明，不阻断 PDE 路径。是否接受失败尝试替代完整实验须由团队结合课程要求评审，不预先视为达标。

## 质量约束

### NFR-01 可复现与可追溯

每次正式运行记录代码提交、契约版本、场景版本 / 摘要、算法配置、环境、随机种子（如适用）、时间范围和结果来源。相同配置按事先声明的数值容差比较；没有实验就不能宣称确定性。

### NFR-02 契约一致与可测试

生产方 / 消费方共同评审输入输出和单位。小型样例进入版本管理；自动检查守住格式与关键语义。真实算法、任务和 UI 的检查随实现加入。

### NFR-03 性能与可用性

第一周声明演示机器、网格和时间范围，第二周测量后制定求解等待时间、结果大小、播放流畅度目标。当前不编造秒数或帧率。失败任务和无效配置给出可读反馈。

### NFR-04 结果诚实

Mock、PDE 与 FNO 结果明确标识；示意动画、数值实验与真实工程性能区分。没有改善或未验证时如实显示。课程比较结果不能作为真实疏散安全结论。
