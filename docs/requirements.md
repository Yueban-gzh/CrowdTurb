# 四周需求基线草案

状态：2026-11-25 用户确认改用 STDDN 个体仿真，见 [ADR 0002](decisions/0002-stddn-trajectory-and-passage.md)。V5 原件保留，下面编号沿用；新接口仍待消费方联调。没有产品需求被标记为已完成。

## 产品与范围

五人四周完成单层场馆原型。用户配置建筑与初始人群，C 运行完整 STDDN 个体仿真，D 聚合密度/速度并分析，B 提供 3D/俯视；评价出口宽度、设施位置与通道宽度候选。

- 必须：示例场馆、基本编辑、真实完整个体仿真、3D 展示、基础指标、真实布局变量、同条件比较和统一入口。
- 模型：真实调用 STDDN，验证路径、碰撞、边界、出入场与持续运行；模型文件能加载不等于仿真已完成。PDE/FNO 不再作为主线必做项，可选对照单独报告。
- 不纳入本轮：完整 CAD/BIM、多楼层、复杂群体行为、精细人物动画、多人在线编辑、复杂 LLM 系统、工程级疏散认证。

## 功能需求

### REQ-01 场景配置与保存

负责人 A，E 提供保存接口。载入单层示例体育馆，修改出口或局部通道和初始密度、边界配置，保存并重新打开。验收时比较修改前后场景文件，确认位置、参数及版本一致，且无须改代码或手工替换数据。非法几何、负密度和不支持的配置应给出可读提示，不能静默运行。

### REQ-02 个体仿真

负责人 C，E 接入。读取 A 最终几何/掩码并更新路径与碰撞，独立运行 STDDN 逐人状态推进；输出稳定 ID、带时间的位置/速度、退出事件及运行元数据。初版固定人员全部 t=0 入场。明确积分步长、目标规划、边界和失败判定；检查人数收支、有限值、不穿障碍、长时稳定性和布局响应。不承诺未经实验的精度、人数规模或速度。

### REQ-03 3D 与俯视回放

负责人 B。读取 A 建筑、C 轨迹和 D 聚合场，显示 3D/俯视、热力、流向和时间控制。真实轨迹与装饰性粒子明确区分；验证坐标、时间和障碍映射。示意粒子数量不能作为人数，仿真轨迹也不等于实测轨迹。

### REQ-04 指标与诊断

负责人 D。从 C 轨迹聚合密度/平均速度，计算残留人数、拥堵面积时间、显式出口累计人数与热点，独立输出分析。注明公式、单位、采样与阈值来源，用手算小场验证。人员消失不能自动当作退出；个体旅行时间如扩展须说明未完成样本和统计口径。

### REQ-05 候选布局与公平对比

负责人 D，A 提供约束，E 调度；D 补充通道宽度。出口、设施、通道候选经几何与可达性检查，实际更新仿真几何。比较固定初始人员/位置/速度/行为属性、随机策略、时长、模型、规划/碰撞与指标口径，仅改变建筑变量。展示指标、修改量、代价和无改善结果；不能用 Mock 或减少人数冒充优化。候选预处理不等于效果评价。

### REQ-06 系统任务与结果管理

负责人 E。统一网页入口连接配置、求解、回放、分析和优化；保存项目、场景版本和运行结果。计算过程有状态，失败有原因。以固定场馆从头到尾演示，无须途中改代码、手动换结果；按说明可重新启动并复现关键结果。

### REQ-07 模型接入与适用性实验

负责人 C。记录 STDDN 权重来源、训练/测试条件和许可、模型哈希、推理及完整 rollout 的稳定性和误差、适用范围与失败案例。ETH/HOTEL 说明不证明高密度场馆有效；在小型受控场验证边界、碰撞、出口和布局变化响应。比较时间包含规划/邻居/碰撞等完整成本。失败如实记录，基准模型和降级方式由 C 提出评审，不回退到未实现的 PDE。

## 质量约束

### NFR-01 可复现与可追溯

每次正式运行记录提交、契约、场景/输入摘要、初始人员摘要、模型及规划/碰撞/积分版本、环境、随机策略、时间范围与来源。相同条件按预先声明的容差/波动比较；没有实验不能宣称确定性。

### NFR-02 契约一致与可测试

生产方 / 消费方共同评审输入输出和单位。小型样例进入版本管理；自动检查守住格式与关键语义。真实算法、任务和 UI 的检查随实现加入。

### NFR-03 性能与可用性

第一周声明演示机器、网格和时间范围，第二周测量后制定求解等待时间、结果大小、播放流畅度目标。当前不编造秒数或帧率。失败任务和无效配置给出可读反馈。

### NFR-04 结果诚实

Mock 与 STDDN 结果明确标识；历史 PDE/FNO 标签不复用于新模型。动画、模型实验和真实工程性能区分；没有改善/未验证如实显示，课程结果不能作为安全认证。
