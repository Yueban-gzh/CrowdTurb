# 风险登记草案

当前均为待跟踪风险，不代表已经发生。每周复盘更新负责人、状态和证据。

- R-01 范围过大，负责人 E：单层、一个真实建筑变量、PDE 闭环优先。若 W2 未有真实场联调，暂停非必要 UI 扩展并缩减候选数量，记录变更。
- R-02 PDE 数值不稳定或指标口径不明，负责人 C/D：W1 明确方程、边界、容差和手算 / 基准检查；真实结果进入展示前完成基础数值验证。不得仅凭动画认定正确。
- R-03 FNO 数据或训练超预算，负责人 C：W1 声明算力和数据预算；W3 前评审可用性，保留真实实验结果，产品继续用 PDE。
- R-04 接口漂移导致等待，负责人 E：Schema、例子和检查同 PR 修改；相关生产方 / 消费方评审；一天以上阻塞用明确 Mock 继续。
- R-05 Mock 被误作结论，负责人 B/D：界面、元数据和报告标注来源；最终优化结论必须关联真实求解记录。
- R-06 比较条件不公平，负责人 D：记录变化参数与固定条件，保留原始场景和求解配置；无法保持同条件时明确标注不能直接比较。
- R-07 课程评价重点不清，负责人 E：向教师确认软件工程过程及 AI 实验要求，保存实际反馈；不能自行声称覆盖所有评分项。
- R-08 结果文件过大或部署失败，负责人 E/C：W2 测量典型输出与加载耗时，评估数组文件存储；W4 从新环境按说明启动演示。
