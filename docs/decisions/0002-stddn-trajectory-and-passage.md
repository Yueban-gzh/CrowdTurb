# ADR 0002 个体仿真路线与 D 聚合职责

日期：2026-11-25。状态：用户在本会话确认方向；接口实现为可评审版本，尚待 C/B/E 实际消费。

同日 D 后续实现：增加自动范围采样、预期输入和运行可比性检查、修改预算与候选比较；聚合场/分析升级 0.3.0，比较契约 0.1.0，C 轨迹保持 0.2.0。原 cell 作为默认，增加实验可见高斯估计供敏感性对照。下文“尚无排名”指没有真实仿真排名，合成流程已有明确来源的推荐。

## 决策

用户确认以 STDDN 个体仿真替代 V5 的 PDE/FNO 主路线，采用新分工，并由 D 补充 A 尚未实现的通道宽度。原始 DOCX 不修改，REQ 编号保留并修订。此决定不代表教师或其他成员已评审，也不代表模型已适用于场馆疏散。

- C：从 A 场景创建固定初始人员，完成推理、路径、碰撞、边界和出入场，输出轨迹与显式退出事件。
- D：轨迹聚合密度/平均速度，计算指标和热点；生成受约束候选，按真实仿真结果评价。
- A：场景、参数声明、几何与栅格校验。D 在 A 分支基础上增加独立通道及宽度修改。
- B：读取轨迹、场和独立分析结果展示，不重算指标。
- E：任务、持久化、结果关联与整体验收。

## 优化变量与通道

主线为出口宽度、固定尺寸矩形展台位置、通道净宽。先证明每个变量进入计算，再组合搜索。当前只有几何预处理，没有完整仿真或改善排名。

A-local 场景升 `0.3`，兼容 `0.1/0.2`；新增 `geometry.passages` 独立 ID、中心、轴向 x/y、固定长度、当前净宽、预留包络宽度、宽度范围和调整权限。两侧隔挡随净宽对称变化，不切除固定结构，不改变中心和连通结构。范围、重叠、人群覆盖、出口净距、可达性和近似通路宽度接受检查。

本轮只在 Python/JSON 支持通道。原 A 网页编辑器拒绝 `0.3`，后续由 A 增加编辑、B 增加展示。不能宣称已有网页通道编辑。格心采样不等于精确工程净空，等效输入按哈希去重。

## 数据与实验

新 `trajectory / derived-field / analysis` 契约提案为 `0.2.0`，与 A-local `0.3` 是不同版本域。旧共享 `0.1.0` 保留作历史 Mock。来源新增 `stddn`，不得标成 `pde/fno`。

初版固定人员全部 t=0 入场，不中途新增、不重入。稳定 ID 和退出事件核对完整性；无故消失、越界、障碍内人员均报错，不认定成功疏散。真实结果须模型哈希、运行记录和配置，元数据本身不证明有效。

密度为格内人数/整格面积；速度为格内速度算术平均，空格为零，不处理部分格面积。每帧保持至下一帧，拥堵量用左端矩形积分，末帧不外推。阈值显式提供并注明来源，A 的 jam_density 和 B 配色阈值不能自动视为同一标准。

公平比较固定初始人员、位置、速度及行为属性、随机策略、时长、步长、模型/规划/碰撞版本和指标，只改变建筑变量。初始状态摘要仅核对 ID/位置/速度，不涵盖全部条件。出口累计人数来自事件。

## 集成条件

C 提供基准及合法候选的完整运行，证明最终掩码进入路径与碰撞；B 适配新契约与指标面板；E 保存关联和失败状态。完成前不标记产品验收通过。PDE/FNO 不再作为主线必做项，可选对照须单独报告。
